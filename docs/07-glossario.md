# Glossário e Referências

## 1. Termos Técnicos
* **HIS**: Hospital Information System.
* **TISS**: Troca de Informação de Saúde Suplementar.
* **AGHU**: Aplicação de Gestão para Hospitais Univesitários.
* **PIN**: Personal Identification Number — senha numérica curta de acesso.
* **Matrícula**: identificador funcional do colaborador no sistema.
* **RF**: Requisito Funcional.
* **RNF**: Requisito Não Funcional.
* **CARE**: Context-Action-Result-Evaluation — framework de especificação testável usado neste projeto.
* **SDD**: Spec-Driven Development — desenvolvimento orientado a especificações.
* **LGPD**: Lei Geral de Proteção de Dados (Lei nº 13.709/2018).
* **TCLE**: Termo de Consentimento Livre e Esclarecido.
* **JWT**: JSON Web Token — formato de token de autenticação.
* **RBAC**: Role-Based Access Control — controle de acesso por perfil.
* **MFA**: Multi-Factor Authentication — autenticação multifator.
* **Protocolo de Manchester**: sistema de triagem que classifica o risco do paciente em cinco cores (Vermelho, Laranja, Amarelo, Verde, Azul), com tempos-meta de atendimento.
* **COREN**: Conselho Regional de Enfermagem.
* **CRM**: Conselho Regional de Medicina.
* **UPA**: Unidade de Pronto Atendimento.
